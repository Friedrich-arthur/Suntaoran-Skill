# Example: Hiring An Operations Lead / 示例：招聘运营负责人

This example is sanitized. It uses a fictional company context and does not contain private employer, candidate, salary, or contact data.

本示例已脱敏，使用虚构公司背景，不包含真实公司、候选人、薪资或联系方式。

## Intake Input / 采访输入

- Role / 岗位: Operations Lead / 运营负责人。
- Scope / 范围: own daily operating rhythm, coordinate sales/support/product handoffs, improve process reliability.
- Business problem / 解决问题: execution is scattered, founders handle too many follow-ups, customer issues lack stable closure.
- Talent profile / 人才画像: high-potential operator with strong reliability, prioritization, communication, and AI-assisted execution.
- Hard requirements / 硬门槛: 3+ years in operations, customer-facing or cross-functional coordination experience.
- Work mode / 办公方式: hybrid.
- Tone / 语气: direct, practical, warm.

## Role Type / 岗位类型

Operations/project role. Use reliability, prioritization, coordination, discretion, and AI-assisted execution as core checkpoints.

运营/项目型岗位。核心评判点使用靠谱交付、优先级、跨部门协调、分寸保密和 AI 提效。

## Output Excerpt / 产出节选

### One-Sentence Positioning / 一句话定位

You will turn scattered day-to-day execution into a reliable operating system, so customer issues, internal follow-ups, and cross-functional work stop depending on founder memory.

你要把零散执行变成稳定运转机制，让客户问题、内部跟进和跨部门事项不再靠创始人记忆推进。

### Internal Checkpoints / 内部评判点

- CP1 Reliable delivery / 靠谱交付: follows through without repeated reminders.
- CP2 Prioritization / 优先级: identifies what must be solved today and what can wait.
- CP3 Coordination / 协调: aligns sales, support, and product without creating noise.
- CP4 Discretion / 分寸保密: handles sensitive customer and business context appropriately.
- CP5 AI-assisted execution / AI 提效: uses AI to summarize, draft, check, and improve workflows.

### Trial Task Excerpt / 试岗节选

Candidate-facing: review a fictional customer escalation, internal notes, and a messy task list. Within 90 minutes, produce a priority list, response draft, owner table, and next-day operating rhythm.

候选人题面：阅读虚构客户升级案例、内部记录和混乱任务清单。90 分钟内输出优先级列表、客户回复草稿、责任人表和次日运营节奏。

Internal hidden traps:

- two tasks conflict in deadline and customer impact;
- one note contains information that should not be forwarded externally;
- one important dependency is missing and should be clarified;
- the task list is too large for 90 minutes, forcing scope control.
