# Hiring Kit Template / 七块作战包模板

Generate both a polished version and a plain-text copyable version unless the user asks for only one.

默认同时生成美化版和纯文本可复制版，除非用户只要求一种。

## 1. Publishable JD / 对外 JD

Include:

包含：

- role title in plain language / 岗位名，用人话；
- one-sentence positioning / 一句话定位；
- company, location, work mode, compensation if provided / 公司、地点、办公方式、薪资；
- responsibilities / 职责；
- must-have traits and requirements / 必备特质与门槛；
- what the company offers / 公司能提供什么；
- application method placeholder / 投递方式占位符。

## 2. Recruiter Notes / 招聘官参考资料

Explain:

说明：

- what this role really is / 这个角色到底是什么；
- why it matters now / 为什么现在重要；
- what success looks like after 30, 60, and 90 days / 30、60、90 天成功样子。

## 3. Hooks And Screening Cues / 钩子与伏笔

Include:

包含：

- JD hooks that attract the right people / 吸引对的人；
- natural deterrents for poor-fit candidates / 自然劝退错的人；
- interview questions with "what this tests" notes / 面试口头测人题，并标注测什么。

## 4. Internal Evaluation Checkpoints + Rubric / 内部评判点与打分表

Mark as internal only. Use `03-checkpoint-rubric.md`.

标为内部。按 `03-checkpoint-rubric.md` 生成。

## 5. Trial Task + Hidden Traps / 试岗任务与隐藏挖坑

Candidate-facing task should be clean and fair. Hidden traps and expected signals are internal only. Use `04-trial-task-traps.md`.

给候选人的题面要干净、公平、边界明确。隐藏挖坑和预期信号仅供内部使用。按 `04-trial-task-traps.md` 生成。

## 6. Candidate Preparation Guide / 候选人准备指引

Public-facing. Include:

对外。包含：

- what the interview will focus on / 面试重点；
- what to prepare / 来前准备；
- what good answers usually include / 好答案通常包含什么；
- what not to over-prepare or fake / 不需要伪装什么。

## 7. Hiring Process And Timeline / 招聘流程与节奏

Default rhythm:

默认节奏：

- D1-D2: publish and source / 上线投放；
- D3-D7: screen and first calls / 初筛初聊；
- D8-D10: trial task and scoring / 试岗评分；
- D11-D14: final interview and offer / 终面与 offer。

Adjust to the user's urgency, market, and role seniority.

根据紧急程度、市场和岗位层级调整。

## Plain-Text Format / 纯文本格式

Use:

使用：

- `【Section】` headings / `【分区】` 标题；
- `——————————` separators / 分隔线；
- numbered responsibilities / 数字编号职责；
- bullet points with `·` / `·` 要点；
- placeholders in `【】` / `【】` 占位符。
