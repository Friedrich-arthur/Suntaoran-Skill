# Checkpoint And Rubric Method / 评判点与打分方法

Use this file to turn a talent profile into measurable evaluation criteria.

用这份方法把人才画像变成可评判标准。

## Method / 方法

1. Extract 3-5 core capabilities from the talent profile.
2. Turn each capability into one checkpoint.
3. For each checkpoint, write:
   - what to observe / 看什么；
   - high-score signals / 高分信号；
   - red flags / 红旗；
   - sample evidence / 可用证据。
4. Mark 1-2 checkpoints as non-negotiable.
5. Mark one bottom-line red flag that can trigger rejection.
6. Create a 100-point rubric and a suggested hiring bar. Default hiring bar: 70+ unless the role is very senior or risk-sensitive.

## Role-Type Dimension Suggestions / 岗位类型维度建议

Adapt these to the real role. Do not copy mechanically.

按真实岗位调整，不要机械照搬。

### Innovation Or Technical / 创新或技术型

- problem definition / 定义问题；
- technical judgment / 技术判断；
- prototype execution / 原型落地；
- learning and transfer / 泛化迁移；
- ownership under ambiguity / 混乱中推进。

### Operations, Project, Assistant / 运营、项目、助理型

- reliable delivery / 靠谱交付；
- prioritization under pressure / 优先级与抗压；
- discretion and confidentiality / 分寸与保密；
- cross-functional coordination / 跨部门协调；
- AI-assisted execution / AI 提效。

### Sales Or BD / 销售或 BD

- discovery and diagnosis / 挖需诊断；
- persuasion and narrative / 说服表达；
- resilience / 抗压；
- pipeline judgment / 盘子意识；
- honesty and expectation management / 诚信与预期管理。

### Professional Functions / 专业职能

- professional rigor / 专业严谨；
- compliance and risk control / 合规风控；
- judgment / 判断力；
- communication / 沟通；
- stability and ownership / 稳定性与责任感。

### Support Or Administrative / 支持或行政

- reliability / 靠谱；
- attention to detail / 细心；
- communication / 沟通；
- service mindset / 服务意识；
- confidentiality / 保密。
