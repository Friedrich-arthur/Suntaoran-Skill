# Trial Task And Hidden Traps / 试岗任务与隐藏挖坑

Trial tasks should test realistic work without exploiting candidates.

试岗任务应贴近真实工作，但不能变成免费劳动。

## Fairness Rules / 公平规则

- Keep the task small and time-boxed.
- State expected deliverables clearly.
- Avoid asking for production-ready work the company can directly use.
- Do not require private candidate data beyond what is necessary.
- Do not include discriminatory, humiliating, invasive, or illegal tests.
- Tell the user when legal, compliance, or employment-law review is needed.

## Design Method / 设计方法

1. Choose one realistic mini-task.
2. Set a clear time box.
3. Define candidate-facing deliverables.
4. Add 3-5 internal hidden traps, each mapped to a checkpoint.
5. Keep hidden traps as internal-only content.
6. Score using the rubric from `03-checkpoint-rubric.md`.

## Trap Types / 挖坑类型

Use only traps that reveal work judgment, not tricks.

挖坑只用来观察工作判断，不要搞脑筋急转弯。

- Conflicting information / 信息冲突
  Tests prioritization and clarification.

- Confidentiality boundary / 保密边界
  Tests discretion, compliance, and judgment.

- Missing information / 信息不全
  Tests proactive clarification and assumption labeling.

- Insufficient time / 时间不够
  Tests scope control and delivery certainty.

- Follow-up reflection / 复盘追问
  Tests method, learning, and AI-assisted improvement.
